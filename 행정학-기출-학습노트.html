문제 1 — 문서를 통한 명령이 효과적인 경우

출처: 기출 1번  |  태그: #명령 #서면명령 #구두명령

문제 (기출 원문)

1. 문서를 통한 명령이 효과적인 경우에 대한 설명으로 가장 적절한 것은?

  1. ① 긴급을 요하는 경우
  2. ② 수행자가 충분한 지식을 가지고 숙련돼 있는 경우
  3. ③ 극비사항의 누설 위험을 방지하고자 할 경우
  4. ④ 명령 내용이 복잡하여 이해하기 어려운 경우

명령 전달 방식 — 한눈에

방식효과적인 상황
구두긴급 · 숙련된 수행자 · 단순한 내용
문서(서면)복잡 · 오해 소지 큼 · 기록 필요

암기: 문서 O = 복잡·정확·기록 / 구두 O = 긴급·숙련·간단·(극비)

보기 소거

  • ① 긴급 → 구두가 빠름 → X
  • ② 숙련 → 구두로 충분한 경우 많음 → X
  • ③ 극비 → 문서는 기록·유출 경로 → 구두 쪽 (함정) → X
  • ④ 복잡·이해 어려움 → 문서로 정확 전달·재확인 → 정답
