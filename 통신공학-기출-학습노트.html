문제 1 — 복합신호의 주파수 성분 (주파수 영역)

출처: 기출 이미지 1번  |  태그: #푸리에 #주파수변환 #정현파 #DC성분

문제

신호

s(t) = 5 + 3·sin(40πt) + 4·sin(100πt) + 7·sin(300πt)

는 주파수가 다른 정현파들이 합쳐진 복합신호이다.

다음 보기 중 s(t)를 주파수 영역에 표현했을 때 나타나는 주파수값(Hz)에 해당하지 않는 것은?

보기주파수 (Hz)
①20
②150
③0
④100

배경지식 — 푸리에(Fourier)란?

한 줄: 푸리에 = 신호 s(t)를 「몇 Hz 성분이 섞였는지」로 쪼개 보는 방법.

왜 나오나?

1번 문제처럼 식이 이미 sin(...) + 상수 형태이면, 굳이 어려운 공식 없이 항마다 Hz만 읽으면 됩니다.
시험 지문에 「주파수 영역에 표현」이라고 쓰면 → 푸리에(주파수 변환) 문제라고 보면 됩니다.

핵심 아이디어
  • 어떤 신호든 (복잡해 보여도) 정현파(sin/cos) 여러 개를 더하면 만들 수 있다.
  • 푸리에 분석 = 합쳐진 신호를 다시 sin/cos(=Hz) 단위로 분해하는 것.
비유 — 교향악
시간 영역주파수 영역 (푸리에)
비유지금 들리는 전체 소리도·라·미 각각 몇 Hz인지
1번 문제s(t) = 5 + sin 3개0, 20, 50, 150 Hz
신호 vs Hz (다시 정리)
신호 s(t)Hz
뭐냐시간에 따라 변하는 값출렁임 1초에 몇 번
1번 예전체 식 (5 + sin…)각 sin의 주파수 라벨
5신호 있음 (직류)0 Hz (출렁임 없음)
3·sin(40πt)출렁이는 신호20 Hz (3은 진폭, Hz 아님)
태그와 연결
태그이 문제에서
#푸리에s(t) → Hz 목록으로 바꾸는 이론·유형
#주파수변환시간 영역 → 주파수 영역
#정현파sin(...) 3개 = 출렁이는 성분
#DC성분5 = 직류, 0 Hz
시험용 — 이것만 기억
  1. 「주파수 영역」 → sin 항마다 Hz 찾기 + 상수는 0 Hz
  2. sin(Nπt) → f = N ÷ 2 Hz
  3. 새 Hz는 생기지 않음 — 식에 있는 성분 Hz만 스펙트럼에 찍힘
  4. 푸리에 적분·공식 전체는 군무원 기출 1번 수준에선 안 나옴 (분해·읽기만)

1단계 — 문제가 묻는 것 정리

  • 시간 영역 s(t) → 주파수 영역으로 옮겼을 때 어떤 Hz가 스펙트럼에 찍히는지 찾는 문제입니다.
  • 보기 네 개 중 「안 나오는」 주파수 하나를 고릅니다. (나오는 것 찾기가 아님)

2단계 — 식을 네 덩어리로 쪼개기

덩어리형태역할
①5 (상수)직류(DC) 성분
②3·sin(40πt)정현파 1
③4·sin(100πt)정현파 2
④7·sin(300πt)정현파 3

팁: 「복합신호」= 여러 주파수가 더해진 신호 → 주파수 영역에서는 각 성분의 Hz만 남습니다 (다른 Hz는 새로 생기지 않음).

3단계 — 암기 공식 (노베이스용)

정현파 일반형:

sin(ωt) ↔ ω = 2πf 읽기: 「sin(오메가 t) ↔ 오메가는 2파이 f」

Hz로 바꾸기:

f = ω ÷ (2π) = (t 앞 계수) ÷ (2π) 예: t 앞이 40π이면 → f = 40π ÷ 2π = 20 Hz

암기 한 줄: 「t 앞에 붙은 π 포함 숫자」를 2π로 나누면 Hz

더 쉬운 암기: sin(Nπ·t) → f = N ÷ 2 Hz  (π는 약분)

식 안의 t 계수계산f (Hz)
40π40π ÷ 2π20
100π100π ÷ 2π50
300π300π ÷ 2π150

4단계 — 상수 5는 몇 Hz?

  • 시간에 따라 안 변하는 값 = 0 Hz (DC)
  • 주파수 영역에서 0 Hz 위치에 한 줄(스파이크)로 나타납니다.

암기: 상수만 있으면 → 0 Hz (③ 보기와 연결해 볼 것)

5단계 — 직접 풀기 체크리스트

아래 표를 직접 채운 뒤, 보기 ①~④와 대조하세요.

성분t 앞 계수 (ω)f = ω ÷ (2π) (Hz)주파수 영역에 나옴?
5(DC)?
3·sin(40πt)40π?
4·sin(100πt)100π?
7·sin(300πt)300π?

마지막 질문: 위에서 나온 Hz 목록에 없는 보기 번호는?

6단계 — 실수 방지 팁

  1. π를 Hz로 바꿀 때 2π로 나누는 것을 빼먹지 않기 (40이 아니라 20이 되는 이유).
  2. sin(100πt) → f는 100이 아님 (보기 ④와 헷갈리기 쉬움).
  3. 「해당하지 않는 것」 → 계산한 목록에 없는 보기를 고르기.
  4. 시험장 손계산: 40π ÷ 2π = 20 처럼 π는 약분되게 쓰면 빠릅니다.

7단계 — 비슷한 기출 패턴

  • A + B·sin(ω₁t) + C·sin(ω₂t) 형태 → 항마다 Hz 하나씩만 보면 됨.
  • 「가장 높은/낮은 주파수」, 「기본 주파수」, 「대역폭」도 같은 변환을 씁니다.

문제 2 — 전송 매체의 신호 전송 손상 요인

출처: 기출 2번  |  태그: #전송손상 #감쇠 #잡음 #왜곡 #채널용량

문제

통신 신호가 목적지까지 전달되는 과정에서 전송 매체에서 발생할 수 있는 신호 전송 손상의 요인으로 가장 적절하지 않은 것은?

보기항목
①채널전송용량 (Channel Capacity)
②잡음 (Noise)
③지연 왜곡 (Delay Distortion)
④감쇠 현상 (Attenuation)

배경지식 — 전송 손상(Transmission Impairment)이란?

한 줄: 신호가 매체를 지나며 망가지·약해지·뒤틀리게 만드는 요인.

시험용 3대 손상 (암기)
손상한글뭐가 일어나나비유
Attenuation감쇠멀어질수록 세기 약해짐멀리서 들으면 소리 작아짐
Distortion왜곡모양·시간이 변함목소리가 찢어져 들림
Noise잡음원치 않는 신호가 섞임라디오 지지직 소리

지연 왜곡(Delay Distortion) = 왜곡의 한 종류 (주파수마다 도달 시간 차이)

채널전송용량은?

채널전송용량 = 매체가 얼마나 많은 정보를 실을 수 있는지(한계·능력)
→ 손상이 아니라 통로의 성능 — 「신호를 망가뜨리는 요인」과 구분

암기: 손상 3형제 = 감쇠 + 왜곡 + 잡음 / 용량 = 손상 X

1단계 — 문제가 묻는 것 정리

  • 「적절하지 않은 것」 = 손상 요인 아닌 보기 1개
  • ②③④가 전형적 손상이면 → 남는 보기 확인

2단계 — 보기 하나씩 판별

보기손상?이유 (한 줄)
② 잡음O불필요한 신호가 섞여 원 신호 훼손
③ 지연 왜곡O왜곡의 일종 — 도착 시간 차이
④ 감쇠O거리·매체에 따라 신호 세기 감소
① 채널전송용량?채널 한계·능력 — 손상과 다른 개념

3단계 — 실수 방지 팁

  1. 용량(Capacity) vs 손상(Impairment) — 다른 개념
  2. 지연 왜곡 — 이름에 «왜곡» → 손상 O
  3. 「적절하지 않은」 = 아닌 것 고르기

4단계 — 비슷한 기출 패턴

  • 손상 3가지 + 대역폭·용량·변조 등 다른 개념을 섞어 출제
  • 「전송 손상이 아닌 것은?」형 반복

문제 3 — 신호 부호화 비트 수 (나이퀴스트)

출처: 기출 3번  |  태그: #나이퀴스트 #대역폭 #전송률 #부호화비트 #잡음없음  |  유사: 2024 기출 12번

문제

통신채널에서 잡음이 없다고 가정하고, 대역폭 200 Hz, 최대전송률 3,200 bps로 전송할 때, 요구되는 신호 부호화 비트 수는?

보기비트 수
①2
②4
③8
④1

배경지식 — 잡음 없음 → 나이퀴스트

조건공식핵심
잡음 없음나이퀴스트R = 2B × n
잡음 있음섀넌R = B·log₂(1+S/N)

B = 대역폭 (Hz) = 200  /  R = 전송률 (bps) = 3,200  /  n = 부호화 비트 수 (구함)

암기: 「잡음 없다」→ 나이퀴스트 / 「2B」확인

1단계 — 공식

R = 2 × B × n 3,200 = 2 × 200 × n

2단계 — 계산

2 × 200 = 400 n = 3,200 ÷ 400 = 8

3단계 — 보기 검산

보기nR = 400 × n
①2800 bps
②41,600 bps
③83,200 bps
④1400 bps

4단계 — 실수 방지

  1. 잡음 없음 → 섀넌 X, 나이퀴스트
  2. 2B의 2 빼먹지 않기
  3. 3200÷200=16 (X) → 3200÷400=8

5단계 — 비슷한 패턴

  • B, R 주고 n 구하기
  • n, B 주고 R 구하기
