1. 나이퀴스트 전송률 (잡음 없는 채널) ★★★★★

R = 2 × B × n   (bps)
변수R 최대 전송률 [bps] · B 대역폭 [Hz] · n 신호 부호화 비트 수(비트/심볼)
설명잡음 없을 때 대역폭 B로 보낼 수 있는 최대 비트율. 준위 수 L이면 n = log₂L로 구한 뒤 공식에 넣음
기출 2025-3: 무잡음·B=200Hz·R=3200bps → 3200=2×200×n → n=8 유사 2024-12: 무잡음·8준위·B=3000Hz → n=3 → R=18000bps (역: R 구하기) · 전체 3번 (2025-3 동일)
응용 2024-12: 무잡음·8준위·B=3000Hz → n=3 → R=2×3000×3=18000bps 유사 2025-3: 무잡음·B=200Hz·R=3200bps → n=8 (역: n 구하기) · 전체 3번
지문힌트

✅ 결정적 키워드 (이게 보이면 나이퀴스트)

키워드해석
「잡음이 없다」「가정하고」+ 잡음 언급 없음가장 강력 — 잡음 없음 → 나이퀴스트
「무잡음 채널」위와 동일
「최대 전송률」「최대 비트율」+ 대역폭 B [Hz]이론적 상한 · 2×B×n 구조
「신호 준위(레벨) 수」「n개의 준위」준위 → n = log₂L 후 R 계산
「신호 부호화 비트 수」「몇 비트로 표현」n을 구하거나 주어짐
「나이퀴스트」직접 언급공식 지정 문제

❌ 피하기: 「SNR」「S/N」「dB」「잡음이 있다」→ 섀넌 · 「baud·bps·QAM」만 있으면 → 변조(3번)

2. 섀넌(Shannon) 채널 용량 (잡음 있는 채널) ★★★★★

C = B × log₂(1 + SNR)   (bps)
변수C 채널 용량 · B [Hz] · SNR 신호대잡음비 (선형, 무단위)
dB→선형SNR(선형) = 10SNR(dB)/10 · 전력 dB 차이: 13dBm−3dBm = 10dB → 선형 10
기출2025-18: B=1MHz, SNR=10dB → C=10⁶×log₂(11) · 2024-12(섀넌): B=4000Hz, SNR=4095 → log₂(4096)=12 → C=B×12 유사나이퀴스트 쌍 → 2025-3 · 2024-12 (노트는 나이퀴스트 풀이)
역산R·B 주고 S/N 구할 때: log₂(1+SNR)=R/B → 1+SNR=2R/B
지문힌트

✅ 결정적 키워드 (이게 보이면 섀넌)

키워드해석
「잡음」「잡음이 있다」「열잡음」잡음 있는 채널 → 섀넌
「SNR」「S/N」「신호 대 잡음비」log₂(1+SNR)에 대입 (선형인지 dB인지 확인)
SNR·전력이 dB로 주어짐먼저 선형 변환: 10dB/10
「채널 용량」「Shannon」「섀넌」공식 지정 · C = B·log₂(1+SNR)
대역폭 B + 전송률 R 주고 「S/N은?」역산: 1+SNR = 2R/B

❌ 피하기: 「잡음이 없다」「무잡음」→ 나이퀴스트 · 「2B」·「준위 수」만 → 나이퀴스트 쪽

3. 심볼율 ↔ 비트율 ★★★★★

비트율(bps) = 심볼율(baud) × n
변수n 부호당 비트 수(비트/심볼) · 변조 이름의 숫자가 레벨 수 M이면 n = log₂M (16-QAM→M=16→n=4)
설명baud=초당 심볼 수 · bps=초당 비트 수 · bps = baud × n
기출 2025-4: 2400 baud, 9600 bps → n=4 → 16-QAM 유사2024-7: 32-QAM, 1M baud → 1M×5=5 Mbps (노트 미등록)
지문힌트

✅ 결정적 키워드 (이게 보이면 baud↔bps·변조)

키워드해석
「baud」「심볼율」「변조속도」「부호율」초당 심볼 수
「bps」「비트율」「데이터전송률」초당 비트 수 — 둘 다 주어지면 n = bps÷baud
「QPSK」「16-QAM」「32-QAM」「BPSK」이름 숫자=레벨 M → n=log₂M (QPSK→n=2, 16-QAM→n=4)
「적용된 변조방식」「가장 적절한 변조」n 구한 뒤 2ⁿ·보기 변조명 매칭

❌ 피하기: 「대역폭 Hz」「무잡음」「SNR」→ 나이퀴스트/섀넌 · 「PCM」「양자화 간격」→ 4번

4. PCM 양자화 간격 ★★★★

Δ = (Vmax − Vmin) / 2ⁿ   (V)
변수
  • Δ — 양자화 간격 (인접 레벨 사이 전압 차, 계단 한 칸) [V] · 보통 구하는 값
  • Vmax — 신호 최대 전압 [V] (예: +8 sin → +8 V)
  • Vmin — 신호 최소 전압 [V] (예: +8 sin → −8 V)
  • Vmax − Vmin — 전압 범위 [V] (위 예: 8−(−8)=16 V)
  • n — 부호화 비트 수 (지문 「3비트」→ n=3)
  • 2ⁿ (= L) — 양자화 레벨 수 (n=3 → 8단계)
설명전압 범위를 2ⁿ개 레벨로 나눔 → Δ = (범위) ÷ (레벨 수). 대칭 sin 문제: Δ = (Vmax−Vmin)/2ⁿ = 2×진폭/2ⁿ
기출2025-5: 8sin(2πft) → ±8V → 범위 16V, 3bit → Δ=16/8=2V
지문힌트

✅ 결정적 키워드 (이게 보이면 PCM Δ)

키워드해석
「PCM」「펄스 부호 변조」「양자화」아날로그→디지털 · 레벨 나누기
「sin(」「진폭」「±○ V」「전압 범위」Vmax−Vmin 구하기
「n bit」「3비트」+ 「레벨 간격」「양자화 간격 Δ」Δ = (범위) / 2ⁿ
「2ⁿ 개의 레벨」레벨 수 = 2ⁿ → Δ = 범위÷레벨 수

❌ 피하기: 「채널 대역폭」「전송률 bps」만 → 나이퀴스트/섀넌 · 「TDM」「프레임」→ 5번

5. TDM 프레임율 · 비트율 ★★★★

프레임율 = (채널 1개 속도) ÷ (프레임당 byte/채널)
총 bit/s = 프레임율 × (프레임당 bit)
설명동기 TDM: 매 프레임마다 채널마다 고정 슬롯 · byte→bit ×8
기출1 2025-8: 동기 TDM·5채널×200byte/s·프레임당 4byte/채널 → 50 frame/s, 5×200×8=8000 bit/s 유사 2025-7: M개 송신 장치 → 프레임 슬롯 최소 M개 (개념)
기출22024-15: 동기 TDM·20채널·16bit/샘플·8kHz·1bit/프레임 → 2.568 Mbps (노트 미등록)
지문힌트

✅ 결정적 키워드 (이게 보이면 TDM)

키워드해석
「TDM」「시분할 다중화」시간 축으로 채널 나눔
「동기 TDM」「Synchronous TDM」고정 슬롯 · 프레임 구조
「프레임」「타임 슬롯」「Time slot」프레임율·슬롯 수 계산
「M개 송신 장치」「채널 ○개」+ 슬롯 개수만개념: 슬롯 최소 = M (기출7)
「byte/s」「프레임당 ○ byte」+ 「bit/s」「프레임/s」계산형 (기출8): 프레임율 = (채널속도)÷(프레임당 byte)

❌ 피하기: 「부반송파 N」「OFDM」→ 6번 · 「주파수 분할·셀」→ FDMA

6. OFDM 전송율 ★★★

전송율 = N × n / T   (bps)
변수N 부반송파 수 · n 부호당 비트 (QPSK→2) · T 심볼 간격 [s] · 1/T = 심볼율
기출2024-13: N=48, QPSK(n=2), T=2μs → 48×2÷(2×10⁻⁶) = 48 Mbps
지문힌트

✅ 결정적 키워드 (이게 보이면 OFDM 전송율)

키워드해석
「OFDM」「직교 주파수 분할」여러 부반송파 동시 사용
「부반송파 ○개」「서브캐리어 N」식의 N
「심볼 간격 T」「μs」+ QPSK/QAM1/T = 심볼율 · 변조→n (QPSK→2)
「전송율」「데이터율」+ 위 세 가지 동시R = N × n / T

❌ 피하기: 「TDM」「프레임·채널 byte」→ 5번 · 단순 「baud·bps」만 → 3번

7. 파장 · 안테나 길이 ★★★

λ = c / f   ·   안테나 길이 ∝ λ ∝ 1/f
변수c ≈ 3×10⁸ m/s (문제: 3×10⁵ km/s) · f [Hz]
기출2024-19: 3GHz → λ=10cm · 2024-16: f 2배 → 안테나 길이 ½ (8cm→4cm)
지문힌트

✅ 결정적 키워드 (이게 보이면 λ·안테나)

키워드해석
「파장 λ」「wavelength」λ = c / f
「주파수 ○ GHz/MHz」「반송파」f → λ 계산 (c ≈ 3×10⁸ m/s)
「안테나 길이」「소자 길이」+ 주파수 변화길이 ∝ λ ∝ 1/f (f 2배 → 길이 ½)
「반파장 안테나」길이 ≈ λ/2 관계 문제

❌ 피하기: 「대역폭·bps·SNR」→ 전송률 공식 · 「dB/km·중계」→ 11번

8. FDMA 셀 용량 ★★★

셀당 사용자 ≈ (총 대역폭 / 채널 대역폭) / 재사용율
기출2024-18: 상향 15MHz, 30kHz/채널 → 500채널, 재사용 4 → 125명/셀
지문힌트

✅ 결정적 키워드 (이게 보이면 FDMA·셀 용량)

키워드해석
「FDMA」「주파수 분할 다중접속」주파수 축으로 채널 분할
「셀」「셀당 사용자」「용량」한 셀에 몇 명 수용?
「총 대역폭 MHz」÷「채널 대역폭 kHz」채널 개수 = 총BW / 채널BW
「재사용율」「reuse」셀당 = (채널 수) ÷ 재사용
「상향」「하향」링크 대역문제에서 지정한 방향 BW 사용

❌ 피하기: 「홉·FHSS·보호대역」→ 9번 · 「TDM·프레임」→ 5번

9. FHSS 전체 대역폭 ★★★

홉 수 N = 2ⁿ
전체 BW = N × (데이터 BW) + (N−1) × (보호대역)
또는 2ⁿ × (홉당 데이터+보호) — 교재·문항 확인
변수n 비트 → 홉 수 N=2ⁿ · 홉당 데이터 BW · guard(보호대역)
기출2025-9: 4bit→N=16, 10kHz/홉, guard 1kHz → 16×10+15×1=175 kHz (16×11=176 형태도 있음)
주의교재에 따라 2ⁿ×(데이터+보호) 한 줄식 vs N×데이터+(N−1)×guard 분리식 → 숫자 확인
지문힌트

✅ 결정적 키워드 (이게 보이면 FHSS 대역폭)

키워드해석
「FHSS」「주파수 도약 확산」홉(hop)으로 주파수 바꿈
「○ bit」→ 홉 수 2ⁿ홉 개수 N
「홉당 ○ kHz」「데이터 대역폭」각 홉이 차지하는 BW
「보호 대역」「guard band」홉 사이 간격 — (N−1)×guard
「전체 대역폭」「스펙트럼 점유」N×(데이터 BW)+(N−1)×guard

❌ 피하기: 「셀·재사용·FDMA」→ 8번 · 「해밍·코드워드」→ 10번

10. 해밍 거리 · 오류 검출·정정 ★★★

dmin = 다른 비트 개수 (XOR 후 1의 개수)
검출 ≤ dmin − 1  ·  정정 ≤ ⌊(dmin−1)/2⌋
기출2025-10: 110111 vs 101101 → HD=3 → 검출 2, 정정 1
지문힌트

✅ 결정적 키워드 (이게 보이면 해밍 거리)

키워드해석
「해밍 거리」「Hamming distance」두 코드의 다른 비트 수
두 이진 문자열·코드워드 나란히 제시XOR → 1의 개수 = dmin
「오류 검출」「몇 비트 오류 검출」검출 ≤ d−1
「오류 정정」「정정 가능」정정 ≤ ⌊(d−1)/2⌋

❌ 피하기: 「전송률·대역폭」→ 1·2번 · 「dB/km·거리」→ 11번

11. 경로 감쇄 (dB · 거리) ★★★

감쇄(dB) = 10 × log₁₀(P1 / P2)  ·  거리 2배 → 약 6 dB 추가(3 dB/km형)
설명전력 비율 → 계수 10 · 1km당 3dB면 거리 2배마다 약 6dB · 중계기는 구간 감쇄 보상
기출2025-22: 3dB/km, 중계 1개, SNR≥10dB → 최대 거리 (기출 ③ 16km 등)
지문힌트

키워드해석

「경로 손실」「감쇄」「전파 손실」10·log(P송/P수) 또는 구간 dB 합
「중계기」「Repeater」구간 나눠 감쇄 보상 후 다시 계산

❌ 피하기: 「채널 용량·SNR으로 bps」→ 섀넌 · 「Vout/Vin 전압비」→ 12번 · 「dBm 정의」→ 14번

12. 전압 dB ★★☆예비

전압 dB = 20 × log₁₀(Vout / Vin)
변수
  • Vout, Vin — 출력·입력 전압 [V] (같은 임피던스 가정)
  • 20 — 전압(진폭)은 전력 dB의 2배 계수 (전력 ∝ V²)
구분전력 dB → 10·log(P₁/P₂) (11번) · 전압 dB → 20·log(V₁/V₂) (이번)
예Vout/Vin=10 → 20 dB · 2배 → 6 dB · ½ → −6 dB
지문힌트

✅ 결정적 키워드 (전압·진폭 dB)

키워드해석
「전압」「진폭」「Vout/Vin」「dB(V)」계수 20
증폭기·감쇠기 전압 이득20·log(이득)
전력·와트·dBm·dBW→ 10·log 또는 14번 dBm

❌ 피하기: 「송신전력 W」「dBm」만 → 14번 · 「경로 km·dB/km」→ 11번

13. AM 변조 지수 μ ★★☆예비

μ = (Vmax − Vmin) / (Vmax + Vmin)
변수
  • μ — 변조 지수 (0~1, 과변조 >1)
  • Vmax, Vmin — 변조된 포락선(Envelope)의 최대·최소 전압
설명AM: 반송파 진폭을 메시지에 비례해 변화 · μ=1 정변조 · μ>1 과변조(왜곡)
예Vmax=8V, Vmin=2V → μ=(8−2)/(8+2)=0.6
지문힌트

✅ 결정적 키워드 (AM μ)

키워드해석
「AM」「진폭 변조」「Amplitude Modulation」μ 공식 후보
「변조 지수」「modulation index」μ 구하기
포락선 최대·최소 전압 둘 다 제시(Vmax−Vmin)/(Vmax+Vmin)
「과변조」「정변조」μ>1 vs μ=1 판별

14. dBm (전력 기준) ★★★보강

PdBm = 10 × log₁₀(P / 1 mW)
변수
  • P — 실제 전력 [W] 또는 [mW]
  • 1 mW — dBm 기준(0 dBm = 1 mW)
  • PdBm — dBm 값 (전력의 dB 표현)
암기1 mW=0 dBm · 10 mW=10 dBm · 1 W=30 dBm · dBm 차이 = 전력 dB(10·log 비율)
연계섀넌·경로문제: 13 dBm − 3 dBm = 10 dB → 선형 SNR=10 (2번·11번과 함께)
지문힌트
